# StudyHub 📚

StudyHub is a simple productivity dashboard I built to keep my daily study tasks, Pomodoro sessions and notes in one place.

I made this project while learning frontend development and wanted to build something that I could actually use instead of just making a random tutorial project.

## What it does

- Add and delete tasks
- Mark tasks as completed
- Filter tasks by All / Active / Completed
- Shows task completion progress
- 25 minute Pomodoro timer
- Keeps track of study time
- Quick notes
- Saves tasks and notes in the browser
- Responsive layout
- Custom pink floral UI

## Built with

- HTML
- CSS
- JavaScript
- LocalStorage
